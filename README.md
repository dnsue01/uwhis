# Uwish · Young With Attitude

Web de una colección de ropa y accesorios de tirada corta. Incluye catálogo, fichas de producto, guía de tallas e información de envíos y devoluciones.

[Visitar la web](https://dnsue01.github.io/uwhis/)

## En el repositorio

El repositorio aloja una exportación estática de Next.js con páginas de catálogo en `catalogo/` y fichas en `producto/`.
